# Nano回执 · 电商知识库智能问答系统

**Nano回执**：基于 **LangChain** 的电商商品知识库问答系统。把商品资料放进知识库，用户在网页上提问，
AI **先查资料、再回答**——每条回答下方都附一张**回执面板**：来源资料、相关度、检索漏斗、耗时逐项披露，可随时展开核对原文。

## 核心能力

- 🔍 **混合检索 + 精排**：向量检索（懂意思）＋ 关键词检索（抓型号）双路人马，再用精排模型精选最相关的资料
- 📎 **引用溯源 + 答案回执**：每条回答下方一张「回执面板」，逐项披露来源资料、相关度、检索漏斗与耗时；点正文里的 `[1][2]` 角标直接定位到对应来源
- 💬 **多轮对话**：自动理解「它 / 这个」的指代（"那它防水吗" → "W1 耳机防水吗"再查）
- ⚡ **语义缓存**：问过或相似的问题秒回复用，回答上标注「来自缓存」
- 🛡️ **不编造**：资料里没有的内容会直说"不知道"，并列出知识库已收录的资料
- 👥 **多用户多会话**：注册登录、每人独立的会话与历史记录（换浏览器/隔天登录都能找回）
- 🗂️ **知识库管理**（管理员）：拖拽批量上传 6 种格式（PDF/Word/Excel/CSV/TXT/MD）、自动解析入库、进度可见
- 📊 **数据看板**（管理员）：提问趋势、缓存命中率、平均响应、被引用资料排行、**未命中问题清单**
- 🌙 深浅主题切换 · 📱 手机浏览器自适应

## 一、首次使用（只需做一次）

| 步骤 | 双击这个文件 | 做什么 | 耗时 |
|---|---|---|---|
| 1 | `scripts\0-检查环境.bat` | 检查电脑环境（可选） | 10 秒 |
| 2 | `scripts\1-首次安装.bat` | 自动安装全部工具包 | 30~60 分钟 |
| 3 | `scripts\2-下载模型.bat` | 下载两个本地 AI 模型（约 3.5GB） | 5~20 分钟 |
| 4 | `scripts\3-构建前端.bat` | 打包网页界面 | 1~3 分钟 |
| 5 | 填配置 | 打开 `backend\.env`：填 `DEEPSEEK_API_KEY=`（Key）和 `ADMIN_PASSWORD=`（管理员密码） | 2 分钟 |
| 6 | `scripts\4-启动系统.bat` | 启动！浏览器自动打开 | 10 秒 |
| 7 | `scripts\5-导入示例数据.bat` | （可选）导入演示商品资料 | 2 分钟 |

> **怎么拿 DeepSeek 的 API Key？** 浏览器打开 `platform.deepseek.com` → 手机号注册 →
> 左侧「API keys」创建 → 马上复制 `sk-` 开头的字符（只显示一次）→ 左侧「充值」充 10 元。
> 注意：填 Key 和"导入示例数据"都需要**先关掉系统窗口**再操作（或按各脚本的提示来）。

## 二、日常使用

- **启动**：双击 `scripts\4-启动系统.bat`（黑色窗口开着 = 系统运行中，关掉 = 停止）
- **访问**：浏览器打开 `http://127.0.0.1:8000`
- **备份**：双击 `scripts\7-备份数据.bat`
- 更多操作（手机访问、改配置、故障排查）见 **`docs\运维手册.md`**

## 三、推荐体验（示例数据）

导入示例数据后，试试这些（也是功能验收题库）：

| 试这个 | 检验什么 |
|---|---|
| `W1 耳机续航多久？` | 基础问答 + 打字机 + 引用卡片 |
| 接着追问 `那它防水吗？` | 多轮指代改写（应正确答出 IPX5） |
| 把上个问题**再问一遍** | 缓存秒回 +「⚡ 来自缓存」徽标 |
| `退货运费由谁承担？` | 售后政策类问答 |
| `你们卖平板电脑吗？` | 兜底回答（列出已收录资料，不编造） |
| 关闭浏览器 → 重新登录 | 历史会话找回 |
| 换 `demo` 账号登录 | 多用户数据隔离 |

## 四、常见问题

**Q：启动提示端口 8000 被占用？** 系统可能已在运行，直接打开浏览器；否则重启电脑。

**Q：回答报「AI 服务暂时不可用」？** 检查 `backend\.env` 的 API Key 和 DeepSeek 账户余额。

**Q：数据在哪里？** 全部在 `backend\data\`；备份用 `7-备份数据.bat`。

**Q：忘记管理员密码？** 双击 `scripts\8-重置管理员密码.bat`。

**Q：模型下载中断了？** 重新双击 `2-下载模型.bat`（自动断点续传）。

## 五、开发者信息

- 技术栈：LangChain 1.4 + FastAPI + SQLite + Chroma + BGE 本地模型 + DeepSeek + Vue 3 + Element Plus
- 改后端代码：`6-开发模式-后端.bat`（热更新）；改前端：`6-开发模式-前端.bat`
- 改启动脚本：改 `tools\bat_src\` 源文件 → 运行 `python tools\build_scripts.py` 重新生成
- 自检工具：`backend\tests\`（冒烟测试、检索质量、端到端检查）
- 文档：`docs\产品方案.md`（方案定稿）、`docs\进度.md`（开发进度）、`docs\运维手册.md`

## 六、目录结构

```
LangchainRAG项目\
├─ scripts\     双击即用的脚本（安装/启动/备份/重置密码）
├─ backend\     后端（Python）
│   ├─ app\     源代码
│   ├─ data\    你的数据（数据库、上传的资料、日志）
│   ├─ tests\   自检工具
│   └─ .env     配置（API Key、管理员密码填这里）
├─ frontend\    前端（Vue）
├─ tools\       脚本源码与构建工具（开发者用）
└─ docs\        文档（产品方案 / 进度 / 运维手册）
```
