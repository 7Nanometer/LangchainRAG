# 💬 LangchainRAG 知识库智能问答系统

一个基于 **LangChain** 的电商商品知识库问答系统：把商品资料放进知识库，用户在网页上提问，
AI **先查资料、再回答**，并标注答案来自哪份资料的哪一段。

---

## 一、首次使用（只需做一次，按顺序）

| 步骤 | 双击这个文件 | 做什么 | 大约耗时 |
|---|---|---|---|
| 1 | `scripts\0-检查环境.bat` | 检查电脑环境是否合格（可选，先看看） | 10 秒 |
| 2 | `scripts\1-首次安装.bat` | 自动安装全部工具包 | 30~60 分钟 |
| 3 | `scripts\2-下载模型.bat` | 下载两个本地 AI 模型（约 3.5GB） | 5~20 分钟 |
| 4 | `scripts\3-构建前端.bat` | 把网页界面打包成成品 | 1~3 分钟 |
| 5 | 填配置 | 打开 `backend\.env` 文件：把 DeepSeek 的 Key 填到 `DEEPSEEK_API_KEY=` 后面，并设置管理员密码 `ADMIN_PASSWORD=` | 2 分钟 |
| 6 | `scripts\4-启动系统.bat` | 启动！浏览器自动打开系统 | 10 秒 |

**怎么拿 DeepSeek 的 API Key（门禁卡）？**
1. 浏览器打开 `platform.deepseek.com`（带 platform 的网址）
2. 手机号注册 → 左侧「API keys」→ 创建 → 复制 `sk-` 开头的那串字符（只显示一次！）
3. 左侧「充值」充 10 元（够用很久）

## 二、日常使用

- **启动**：双击 `scripts\4-启动系统.bat`，保持窗口开着 = 系统运行中
- **停止**：关掉那个黑色窗口即可
- **访问**：浏览器打开 `http://127.0.0.1:8000`（启动时会自动打开）

## 三、常见问题

**Q：启动时提示端口 8000 被占用？**
A：系统可能已经在运行了，直接打开 http://127.0.0.1:8000 试试；不是的话关掉占用程序。

**Q：回答报错「AI 服务暂不可用」？**
A：检查 `backend\.env` 里的 `DEEPSEEK_API_KEY` 是否填对、DeepSeek 账户是否有余额。

**Q：想换一台电脑装？**
A：把整个项目文件夹拷过去，按"首次使用"走一遍即可。

**Q：数据在哪里？怎么备份？**
A：数据全部在 `backend\data\` 文件夹。双击 `scripts\7-备份数据.bat` 一键打包备份。

**Q：模型下载中断了怎么办？**
A：重新双击 `2-下载模型.bat`，会自动接着下载（断点续传）。

## 四、开发者信息（普通使用可忽略）

- 技术栈：LangChain 1.4 + FastAPI + SQLite + Chroma + Vue 3 + Element Plus
- 改后端代码：`6-开发模式-后端.bat`（自动热更新）
- 改前端代码：`6-开发模式-前端.bat` + 后端（浏览器访问 5173 端口）
- 文档：`docs\产品方案.md`（定稿方案）、`docs\进度.md`（开发进度）

## 五、目录结构一览

```
LangchainRAG项目\
├─ scripts\     所有双击即用的脚本（安装、启动、备份）
├─ backend\     后端程序（Python）
│   ├─ app\     源代码
│   ├─ data\    你的数据（数据库、上传的资料、日志）
│   └─ .env     配置文件（DeepSeek Key 填这里）
├─ frontend\    前端网页（Vue）
└─ docs\        项目文档
```
