# 运维手册 —— 日常使用与问题排查

> 平时遇到问题，先来这里找答案。找不到再联系技术方，附上日志文件内容。

## 一、日常操作速查

| 我想…… | 怎么做 |
|---|---|
| 启动系统 | 双击 `scripts\4-启动系统.bat`，**黑色窗口开着 = 系统运行中** |
| 停止系统 | 关掉黑色窗口即可 |
| 打开系统 | 浏览器访问 `http://127.0.0.1:8000`（启动时会自动打开） |
| 备份数据 | 双击 `scripts\7-备份数据.bat` |
| 检查电脑环境 | 双击 `scripts\0-检查环境.bat` |
| 重置管理员密码 | 双击 `scripts\8-重置管理员密码.bat` |

## 二、账号

- **管理员**：用户名 `7Nanometer`，密码是你配置的（保存在 `backend\.env` 的 `ADMIN_PASSWORD`）
- **普通用户**：让同事/客户自己在登录页点「立即注册」即可；他们只能问答，看不到管理功能
- **修改密码**：登录后 → 右上角头像 → 个人设置 → 修改密码（推荐用这个方式）
- **忘记管理员密码**：双击 `scripts\8-重置管理员密码.bat`（建议先关掉系统窗口再运行）

## 三、知识库维护

### 日常上传
管理后台 → 知识库管理 → 点进知识库 → 把文档拖到上传框 → 等状态变「已完成」。
支持：PDF、Word、Excel、CSV、TXT、Markdown，可一次拖入多个（单个 ≤50MB）。

### 让回答越来越准
1. 打开「数据看板」→ 看「**未命中问题**」清单——这里记录着用户问了但知识库答不上的问题
2. 把这些问题的答案整理成文档（Word/Excel/文本都行）
3. 上传到知识库 → 以后同类问题就能答上了

### 资料更新了怎么办
用新版文件重新上传一份即可（同一份资料建议先删旧的再传新的，避免新旧内容混在一起）。
如果只是部分内容修改，也可以对单个文档点「重建」前先替换——推荐做法：**删掉旧文档 → 传新文档**。

### 某些文件处理失败
看失败原因提示：
- 「疑似扫描件」→ 你的 PDF 是图片扫描版，换成文字版 PDF 再试
- 「格式不支持」→ 用 Word/Excel 另存为受支持的格式
- 其他原因 → 截图发给技术方

## 四、备份与恢复

**备份**：双击 `scripts\7-备份数据.bat` → 备份 zip 文件出现在 `F:\LangchainRAG-data\backups\`。
建议：每周一次；大批量上传资料之后加做一次。

**恢复**：关掉系统窗口 → 把备份 zip 解压，用里面的内容覆盖 `backend\data\` 整个文件夹 → 重新启动系统。

备份包含：账号、全部对话记录、知识库文档、上传的原始文件、问答缓存。**不包含**程序代码和 AI 模型（它们坏了可以重装）。

## 五、让手机/同事也能访问（局域网）

默认只有本机能访问。要让同一个 WiFi 下的手机或同事电脑访问：

1. 用记事本打开 `scripts\环境配置.bat`，找到 `set "SERVICE_HOST=127.0.0.1"`
2. 把 `127.0.0.1` 改成 `0.0.0.0`，保存
3. 重新双击 `4-启动系统.bat`（Windows 防火墙弹窗时选「允许访问」）
4. 查看本机 IP：按 `Win+R` 输入 `cmd` 回车，在黑窗口输入 `ipconfig` 回车，
   找到「IPv4 地址」（如 `192.168.1.5`）
5. 手机/同事电脑浏览器访问 `http://192.168.1.5:8000`（把 IP 换成你查到的）

⚠️ 注意：局域网内所有人都能打开这个网址，请知悉（登录仍需账号密码）。
外网（不在同一 WiFi）访问需要额外的网络配置，超出本手册范围。

## 六、改配置（backend\.env 文件）

文件里每一项都带中文注释。**改完必须重启系统**才生效。可改的常用项：
- `DEEPSEEK_API_KEY`：换 API Key
- `RATE_LIMIT_PER_MINUTE`：每用户每分钟提问上限（默认 20）
- `CACHE_SIMILARITY_THRESHOLD`：缓存相似度阈值（默认 0.92，调低=更容易命中缓存）

## 七、常见故障排查

| 现象 | 解决 |
|---|---|
| 双击启动脚本报错/闪退 | 看窗口里的中文提示；多半环境未装好 → 重新跑 `1-首次安装.bat` |
| 提示「端口 8000 已被占用」 | 系统可能已在运行 → 直接开浏览器试；否则重启电脑 |
| 浏览器打不开页面 | 确认黑色窗口还开着；地址是 `http://127.0.0.1:8000` |
| 回答报「还没有配置 API Key」 | 把 DeepSeek Key 填进 `backend\.env` 后重启 |
| 回答报「AI 服务暂时不可用」 | 检查 DeepSeek 账户余额；检查电脑网络；稍后重试 |
| **第一**次提问特别慢（转圈 30 秒） | 正常：AI 模型正在加载，之后就快了 |
| 上传后一直「处理中」 | 大文件需要 1~5 分钟；超过 10 分钟查看日志 |
| 电脑风扇变响/变卡 | 模型运行时占用显卡属正常；不用时关掉系统窗口 |
| 回答内容不准确 | 到「数据看板」看引用原文；补充/修正资料后重传 |
| 界面显示旧版本 | 浏览器按 `Ctrl+F5` 强制刷新 |

## 八、日志与求助

- 日志文件：`backend\data\logs\app.log`（记录每步操作和报错；满 10MB 自动滚动）
- 向技术方求助时：**描述你操作的步骤 + 截图（含窗口里的中文报错）+ 附日志文件**

## 九、软件更新流程

拿到新版本后：
1. 重新构建前端：双击 `scripts\3-构建前端.bat`
2. 重启系统：关掉黑色窗口 → 双击 `scripts\4-启动系统.bat`
3. 浏览器按 `Ctrl+F5` 刷新

数据不会有任何影响（升级只会动程序代码）。
