### 验收方法（M1）
1. 双击 `scripts\4-启动系统.bat`，浏览器自动打开登录页
2. 用管理员账号 `7Nanometer`（密码在 `backend\.env` 的 ADMIN_PASSWORD 里）登录 → 右上角能看到「管理后台」入口
3. 注册一个新账号 → 登录 → 个人设置里改密码 → 退出 → 用新密码登录成功
4. 普通账号登录后：右上角菜单里**没有**「管理后台」；手动在地址栏输入 /admin/dashboard 会被弹回
